来源文件为用户提供的《第28届CPHOS物理竞赛联考理论试题解答》，24页，SHA-256 `dd8c5bbc2f46180d39b7736731cc630048b5cb6ec07937a41da45d1c67c78c80`。原PDF版权归原作者，仓库不附PDF或整页图像。页码均为PDF的1-based页码。

所有7个片段在 `sources.json` 中独立登记：页码、公式编号、规范化说明和逐式核对说明。新片段没有复用旧 `sources.json` 的文本或ID；其中Q2选录是参考答案的中间数值和张力关系，Q6选录是传递矩阵和有限链边界几何，Q7选录是逆时间坐标。AI已视觉核对第5、18、19、23页，保留正负号、相位中的tau、分母2及量纲因子，未使用旧来源审查列出的疑似错误公式。JSON中的规范化文本是引用匹配对象，不声称与PDF文本层逐字一致。

新样例遵循已公布粒度规则：同一命题的等价文字与公式合并；不等价则拆开。Q7两个gold的 `answer_quote` 均为回答的连续原文片段，未为取得标签而改写错误内容。Q6的矛盾依据允许一步矩阵乘法；其问题是一般参数关系不成立，不声称某个特殊tau下绝无巧合相等。

结构检查和导出已通过：

```powershell
python scripts/validate_dataset.py --dataset dataset/cphos28-review/cases.jsonl --check-local-sources
```

`scripts/build_review_samples.py` 保存构造逻辑，现有样例或审阅文件存在时拒绝覆盖。原始事实与gold不会随模型输出改变。`inputs.jsonl` 仅含端点请求；`manifest.jsonl` 和 `gold.jsonl` 单独保存元数据与建议标签。
