# 结果解释与复现

本页解释发布首页引用的两组不同评测。主线入口为 `optimized-v4.0`；历史报告中的 `optimized` 名称按当时的配置解释，不随当前别名改变。

## 新 RAGTruth 180：回答级检测

2026-10-24的实验在30个来源组、180个原始回答上比较baseline、minimal、v4.0。每来源保留6个生成模型回答，QA/Summary/Data2txt各10个来源；原生阳性58、阴性122。数据用于这轮推理前未被本项目使用；实验后已曝光。

预注册提交 `7a23bc4`，取数前冻结65个文件，数据绑定提交 `532e083`，完整结果归档于 `bd51922`。先排除70个已曝光来源和1个重复请求来源，共71个排除组，其中68个来自官方test、3个来自既往train smoke。**不是71个历史曝光test来源。** 标签不参与抽样或推理；模型只接收原文段落与答案。

采用官方固定版本 `c103204b9ce28d6bbad859304bf30de72b8ed8fe` 的test、quality=good，按固定哈希排序取组。来源、回答、相同上下文和规范化请求均核对无历史交集。QA仅提供证据段、未加入问题；Summary保留原文，Data2txt完整序列化JSON。这个适配器定义了所测任务，不能直接与论文中的其他输入设置比较。

### 固定评分口径

原生标签非空即“回答含幻觉”；有效报告中任一已完成C/U即预测阳性。

| 返回结果 | 回答级预测 | 计分方式 |
| --- | --- | --- |
| complete，全S或合法空claims | 阴性 | 根据原生标签计TN/FN；空报告单列 |
| complete，含C/U | 阳性 | 计TP/FP |
| partial，已完成部分含C/U | 阳性 | 可计TP/FP，但报告仍属部分完成 |
| partial，全S；或执行/契约错误 | unknown | 不计TP/FP/TN/FN，保留在全部180分母中 |

主指标为 `(TP+TN)/180`。条件准确率、precision、recall、F1只对已决样本计算，必须同时报告未决与完整率。RAGTruth没有完整原子claim语义金标，不能由此声称三分类准确率、事实提取召回或语义引证正确率。

| 指标 | baseline | minimal | v4.0 |
| --- | ---: | ---: | ---: |
| TP / FP / TN / FN | 58 / 122 / 0 / 0 | 55 / 89 / 33 / 0 | 56 / 73 / 47 / 2 |
| unknown：阳性 / 阴性 | 0 / 0 | 3 / 0 | 0 / 2 |
| 正确 / 全180 | 58 / 180 | 88 / 180 | 103 / 180 |
| 已决precision | 32.22% | 38.19% | 43.41% |
| 已决recall | 100.00% | 100.00% | 96.55% |
| 已决F1 | 48.74% | 55.28% | 59.89% |
| 完整 / 部分 / 错误 | 180 / 0 / 0 | 177 / 0 / 3 | 175 / 5 / 0 |
| 合法完整空claims | 0 | 0 | 3 |

baseline本轮全部报阳；minimal的三个阳性未决不能被隐藏成“零漏检”。v4的五份partial中三份可形成阳性判定，两份全S未决。其1384/1393已提取目标完成率只衡量执行完成，不是事实召回率。

### 配对不确定性

30个完整来源簇共享重抽样，每次保留同源6个回答及所有后端，2,000次、seed=20261024。v4减minimal：

| 指标 | 差值（百分点） | 95%区间 |
| --- | ---: | ---: |
| 正确 / 全180 | +8.33 | [+0.56, +17.22] |
| 已决F1 | +4.62 | [−0.29, +9.73] |
| 完整报告率 | −1.11 | [−4.44, +1.67] |

共同已决175条中，v4独赢23、minimal独赢10；这只是事后条件子集，不能替代全180比较。主指标支持这批来源上的改善，F1区间仍跨零；单轮生成和30来源不能证明跨领域、跨模型稳定领先。

### 预算、费用与时延

minimal一次调用，thinking enabled、输出上限16384；v4拆分/核查disabled、8192，复核enabled、16384，保留内部并发和有限修复。四案例外层并发，每例内三后端顺序预先打散。这是现有系统比较，不是等预算消融。

minimal共180次调用，均值32.207秒、P95 55.250秒；v4共1434次，均值18.413秒、P95 39.796秒。均值是每个回答完整verify调用的墙钟时间，不是子调用均值；也不等于包含服务排队的HTTP用户延迟。

固定参考单价为USD/百万token：输入0.30、缓存输入0.006、输出1.20，reasoning已在输出内。按记录缓存份额，minimal完整估算$1.456009，v4已知小计$1.087671；统一未缓存时分别$1.483330、$1.548437。v4两次连接错误缺usage，两口径总额都未知，不能宣布完整成本节省。不是当日价格或实际账单。

### 已知边界

“永远判干净”的准确率为122/180=67.78%，但检测recall/F1为0；当前系统仍过度举报。原生FP不是作者裁定真FP，原生FN=2也不满足此前另定的FN=0验收线。事实选择、覆盖协议和证据蕴含仍需改进，冻结报告不冒充人工终审。

[发布版结果导览](../reports/ragtruth-fresh180-20261024/README.md)列出完整机器报告、独立审计和证据包。[离线复算说明](../reports/ragtruth-fresh180-20261024/REPRODUCE.md)无需API即可重算所有540条结果。原始文件与历史路径说明保留在证据包及[固定归档提交](https://github.com/yixiaogithub66/citation-grounding-verifier/tree/bd51922/research/ragtruth-fresh180-20261024)。

## CPHOS：历史claim级比较

原数据集46条、58个标准claim，开发18、测试24、边界4，按整道题分组；覆盖完全支持、细微篡改、外部幻觉、跨段综合与混合答案。旧test中的24条、32个gold claim用于首页v2三方案表。

该表的严格F1同时要求claim文本对齐与verdict正确，惩罚改写、过拆、漏提及多提。因此minimal 89.23%、v2 86.57%的差距不能直接换算为语义准确率差。历史报告里的 `optimized` 是v2，不是本发布版的别名目标。旧test已进入后续诊断，当前运行只能称回归。

原样保留的[报告](../reports/test/report.md)与[JSON](../reports/test/report.json)记录原始分母、用量和对齐诊断。历史v3.1的12条确认集来自同来源同题族，97.62%的严格F1也不等于跨领域泛化；参见[历史结果索引](HISTORY.md)。
