本复核于 2026-10-22 在 `report.json` 达到 `status=complete`、`completed_records=48/48` 后定稿。复核读取冻结后的 12 条输入、42 条 gold、48 条原始结果及调用记录；独立按文本规范化后的一对一精确匹配重新计算 strict 指标，并检查 approximate 对齐、引文与干预记录。未调用额外 LLM、重复实验、修改代码或回写标签。本文件为独立 AI 结果审计，不冒充作者逐条审阅。

## 运行与结果

四路使用相同的 12 条确认样例；LLM 路径使用 `deepseek-flash`、`thinking=enabled`。全部 48 条输出结构有效，没有技术失败或修复调用。三路 LLM 合计 63 次真实 API 调用，均为 HTTP 200、`finish_reason=stop`，返回相同的模型名和 `system_fingerprint=e72d3c7f663d3e1383b00b3884cb4501`。baseline 是本地规则，无 API 调用。

F1 为 `2 * 判对数 / (gold 数 + 预测数)`，不是把所有失分都视为标签判断错误。Strict 只规范化 Unicode 和空白，保留标点、限定词和文字表达差异；approximate 是保守词法匹配，也不是人工语义评分。

v3.1 相对 v2 的 strict/approximate F1 均提高 **6.9214 个百分点**，整例正确从 9/12 到 11/12。两个改进样例为 `density-q6`、`reformulation_calculation-q2`，没有样例回退。相对 minimal 的 strict 提高 39.4795 个百分点、approximate 提高 20.8749 个百分点；差距包含声明边界与措辞对齐收益，不能全部称为语义判断能力提升。

## 仍然存在的语义错误

完整 ID 均以 `cphos28-confirmation-` 开头。

- **三路 LLM 均误判 `scope_distractor-q2-c1`：gold 为 UNSUPPORTED，预测为 CONTRADICTED。** 证据将 `T*cos(theta)=T_0` 归于悬链线部分，并另列自由悬挂部分的关系。这不能排他地证明前式没有在自由悬挂部分出现；预测自行增加了“而不是/不能归于”的排他关系。v3.1 的两个引文都真实，但合起来仍不足以确立矛盾。其结构化 `conflict` 通过门控，没有进入复审。这是 v3.1 的唯一最终标签错误，不能按“引文合法”宣布修复。
- **minimal 误判 `scope_distractor-q6-c1`：UNSUPPORTED → CONTRADICTED。** 内部连接点位移连续并不排除该位移恰为零，也不能支持“所有内部点额外受零位移约束”；上下文没有这个额外约束。v2、v3.1 均正确保留 UNSUPPORTED。
- **minimal 对 `density-q2-c2` 过拆，且将文字半句判为 UNSUPPORTED。** “任意适用角度下张力竖直分量恒为 T_0”与后接 `T*sin(theta)=T_0` 是同句一致冗余表达，gold 合为一条 CONTRADICTED。minimal 把公式判 C、文字判 U；根据输入斜率定义和张力关系，后者也不是单纯的未知信息。v2 与 v3.1 均保留整体并正确判 C。

v3.1 的最终标签分布为 S15/C14/U13，对应 gold 的 S15/C13/U14；那一项 U→C 就是上面的 q2 归属错误。其余 41 条与 gold 精确对齐且标签一致。没有因本次结果而提出需改写 gold 的新结论，也没有修改首轮成绩。

## 引文复核

| 后端 | 引文均为原文子串 | Strict 证据段覆盖 | Approximate 证据段覆盖 | 必需多段前提覆盖（strict） | 完整 gold 引文包含 |
| --- | ---: | ---: | ---: | ---: | ---: |
| baseline | 1/1 | 1/28 | 1/28 | 0/5 | 1/33 |
| minimal | 37/37 | 18/28 | 21/28 | 3/5 | 3/33 |
| optimized-v2 | 38/38 | 26/28 | 26/28 | 4/5 | 9/33 |
| optimized-v3 | 36/36 | 28/28 | 28/28 | 5/5 | 10/33 |

分母 28 是 gold 中需证据的 S/C 声明数；分母 5 是明确要求多个前提段的声明数；分母 33 是 gold 引文条数。覆盖计数还要求声明对齐及 verdict 正确，因此 v2/minimal 的部分覆盖失分来自过拆或改写，不能全部解释为遗漏证据。对于计算题，三路 LLM 的原始输出都实际提供了必要公式，v3.1 五个需多段证据的声明均在冻结评分下获得完整覆盖。

gold 常引用整句，而模型常只引用公式。比如 `tan(theta)=dy/dx`、完整的 A/B 公式、两个消元前提，虽未覆盖 gold 的整句文本，仍提供了必要关系；10/33 的完整 gold 引文包含率不是 23 条虚构或错误引文。

同时，逐字有效不等于语义充分：q2 归属错误就是反例。另有引文粒度注意项：minimal 和 v3.1 在 `mixed_truth_compound-q6-c1` 只引 `-exp(-i*phi)*i*q`，独立展示这个短片段时没有标明它是 p_1 的第一分量。所引第 0 段完整向量确能支撑标签，故未发现 gold 标签错误；但若产品只展示 quote 而隐藏段落，建议未来版本带上向量名和分量结构。该建议不改变本次覆盖指标或首轮结果。
