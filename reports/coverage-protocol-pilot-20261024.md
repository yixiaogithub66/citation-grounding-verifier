# 覆盖协议新样本对照实验

2026-10-24。**来源单元账本改善了本批 M1 的完成可用性；但事实选择出现退步，ID 账本的成本也高于原协议，尚未达到同时改善完成率、保真与成本的门槛。暂不合入生产。**

实际运行模型为 `deepseek-flash`，Gemini 通过 Antigravity CLI headless High 参与设计反证和结果复核，没有操作桌面。本轮测首次 M1 提取，不包含 M3、重试、fallback 或完整 `/verify`；以下不是整个核查系统的准确率。

新材料是独立 AI 角色起草的 **20 个回答**，五个新领域，中英各十个：15 个含事实/混合回答、五个纯非事实回答，共 44 个预先标注目标。每个回答重复两次、三臂各一次调用，共 **120 次**。每臂分母为 40 次输出、88 个目标机会、10 次纯非事实输出，独立回答仍只有 20 个。材料未使用旧 benchmark 原文；虽然换了领域，多数仍是转录、交接和编排建议，形式分布有限。目标与评分均为 AI 审阅，不冒充作者终审。

**实验改变了来源记账方式，语义任务保持一致。**

| 实验臂 | 输入及输出 | 确定性检查 |
|---|---|---|
| 原 M1（legacy） | 原回答；claim 与 non-factual 均返回原文子串 | 原有逐字子串、出处顺序和有意义字符覆盖 |
| 抄写账本（ledger_text） | 完整回答按来源单元显示；每单元返回 ID、claim 关联、NF 理由，并抄原文 | 每单元显式记账、ID/引用合法、原文回显精确 |
| ID 账本（ledger_id） | 与抄写账本相同输入及共享提示；只省去原文回显 | 相同账本检查，代码按 ID 取回原文 |

来源单元按固定标点/换行划分，能逐字符拼回原回答，不归一化数字、符号或字母。单元不是原子事实；一单元可以有多个事实，一个 claim 也可关联多单元。代码只稳定排序和定位，不改 claim 文本、不合并/去重，也不把遗漏单元自动补成 NF。mixed 单元由模型同时给出 claim 关联及 NF 理由，不整段排除。来源只保留实际离散片段，没有虚构连续包围引文。

新账本是**较粗的覆盖契约**，不能与旧字符覆盖等同。它可以在只挂一个 claim 时漏掉同单元的第二个事实，因此主指标要求结构有效之外，还要所有事实保留、无建议误纳、每条 claim 独立自足、归属/条件/来源/原子性正确。两账本之间主要比较回显负担；与原协议之间则是整体表示和协议的比较，不能把全部差异都归因于 ID。

| 主口径 | 原 M1 | 抄写账本 | ID 账本 |
|---|---:|---:|---:|
| **严格完成且保真 /40** | **23** | **28–29** | **30** |
| 原始回答两次都严格通过 /20 | 8 | 10–11 | 14 |
| 各自协议下结构有效 /40 | 33 | 37 | 40 |
| 完成的事实内容保留 /88 | 73 | 83 | 88 |
| 内容选择通过 /40，尚不要求全部独立自足 | 32 | 34 | 35 |
| 完成的独立自足目标 /88 | 64 | 73，另 1 未定 | 81 |
| 纯 NF 正确且有效 /10 | 7 | 9 | 9 |
| 有效输出中含误纳 claim 的回答 | 1/33 | 3/37 | 5/40 |

严格分数区间来自抄写账本的一条重复所有格措辞：可理解为原文同一命名批次，但独立表达不够明确；保留上下界，没有替模型改写后算成功。

**完成收益成立，但不能写成“修好了 15 个事实遗漏”。** 原协议七次失败均为覆盖记账问题；这七份 raw 输出仍可读，其中涉及的 15 个事实目标全部已经提取。把有效与可读无效输出一起作内容诊断，原 M1 与 ID 账本均保留 88/88，抄写账本为 83/88，另五个目标因传输失败未知。无效 raw 仅作诊断，没有升级为成功。

ID 相较原 M1 的严格通过净增 7 次，正好来自原七个 coverage-invalid 位置全部获得严格通过。**共同结构有效的 33 对里，两者严格通过均为 23/33**，其中三处获益、三处退步互抵；不能解释成逐条语义无退步。保持全 40 分母作主表，同时呈现该诊断，避免隐藏可用性收益或误称语义能力提升。

同单元多事实子集只有三个独立回答、六个目标、两次重复形成 12 个机会：原 M1 完成保留 8/12、raw 保留 12/12；两账本完成/raw 都为 12/12。没有观察到粗账本掩盖真实遗漏，但本批没有可判的真实漏提机会，因此**未观察到掩盖不等于证明安全**。

**ID 与抄写账本的完成差距，不能归因于复制准确性。** 抄写账本三次失败都是传输失败；37 份实际收到的输出中，267 处 source_text 全部逐字精确，没有回显或 ledger schema 拒绝。两账本收到响应后的结构通过均为 100%。

在两账本共同有效的 37 对中，抄写账本内容选择通过 34、严格通过 28–29；ID 分别是 32 和 27。因此全分母 30 对 28–29 的排名夹杂了三次传输差异，不能据此声称 ID 提高语义保真。这是补充诊断，不用共同有效子集替代全分母。

**主要语义代价是建议误纳和指代未展开。** ID 的明确退步包括把“缩短说明、不要缩写数值”的编辑建议改成比较判断，把询问/留白建议改成多条 could/recommended 断言，以及把请同事核对标签抽成 can be compared。还有两次把编排引导句当作事实，其边界另作敏感性分析。`Its / 这块标本 / the specimen` 未展开的问题仍存在：它们可从整段恢复内容，但不满足独立 claim 的严格要求。

为避免有效率差异扭曲误纳比较，额外核对全部可读输出：原 M1 含误纳的回答是 3/40（其中两个结构无效），ID 是 5/40；抄写账本已知三个，另三个传输失败未知。主口径下的语义退步不完全是有效分母变化造成的。

**成本：ID 比抄写省，但比原协议更贵。**

| 40 次计划调用的参考费用 | 原 M1 | 抄写账本 | ID 账本 |
|---|---:|---:|---:|
| 费用已知次数 | 40 | 37，另 3 未知 | 40 |
| 缓存口径 USD | $0.014892 | 已知小计 $0.023447 | $0.019025 |
| 全部输入按无缓存估价 USD | $0.019520 | 已知小计 $0.030070 | $0.026098 |
| 全尝试耗时均值 / P95，秒 | 3.286 / 7.859 | 4.491 / 14.859 | 3.109 / 8.390 |

ID 相较原 M1 的无缓存参考费用增加 **33.70%**，超过预登记的 1.30 倍上限。相同 37 个已知用量配对中，ID 为 $0.0241698、抄写为 $0.0300699，下降 **19.62%**；这只适用于该共同子集。抄写全 40 次费用未知，不能编造精确全量降幅。ID 的均值耗时略低而 P95 更高，不构成延迟全面改善的结论。

参考价沿用项目固定口径：每百万 input $0.30、cached input $0.006、output $1.20；不是当前报价或服务商账单。117 次已知调用合计输入 98,289、输出 38,501，共 136,790 tokens；全实验已知缓存参考小计 $0.057363762、全无缓存小计 $0.0756879，另三次用量/费用未知。请求为 thinking disabled，服务端未给独立 reasoning 用量，不把字段缺失说成测得零。

**敏感性与评分边界已公开。** 四条“另两项属于交接卡”的输出主口径按编排引导/NF 处理；若宽松接受为文档元断言，抄写与 ID 各增加两次选择/严格通过。两条原 M1 引文没有包含 recorded-route 限定前缀，主来源口径失败；若允许同句范围语境补足，原 M1 严格分从 23 到 25。抄写的重复所有格另保留独立自足区间及更严格实体变化解释。忠实同句重复从未当作 FP；来源可从完整答案恢复明确的共同先行词，不能因此随意补入未引用的条件或谓词。这些边界都不消除成本超限和新增明确建议误纳的证据。

本轮的严格自足/来源联合指标比上一轮仅“选择保真”更全面，不能直接把两轮分数作版本涨跌。指标在这次推理前已规定，逐条评阅隐藏了臂名、echo 字段、提示和成本；来源形状仍可能暴露旧协议，因此只称流程盲法。初评、交叉意见、协调修订与最终评分均保留，未作作者终审标记。

**推进门槛未通过。** 完成率及两次皆通过的回答数提高；但是成本超限，误纳没有做到不增加，与抄写账本相比的严格保真非劣也没有得到支持。因此保留实验实现和运行日志机制，暂不替换生产 M1。没有继续针对本批改提示、加案例规则或重跑选优。

本轮 120 个计划请求均有唯一持久化 reservation、response 和单次 attempt，没有恢复、重发、I/O 警告或遗失调用预留。三次传输失败保持失败，远端执行/计费结果未假定为零。117 个完整响应为同一模型/fingerprint并正常停止，无可观察的 token 截断。冻结的 56 个文件及逐请求哈希通过审计；39 项无网络检查覆盖协议、运行耐久性和盲审导出。生产 `grounding / configs / prompts` 相对 `e78fa35` 未改变。预登记提交为 `dc1cbc0`。

Gemini High 两次咨询共报告 35,609 tokens，单独记账。它同意暂不合入，但关于“抄写已被证明提供语义锚定”以及“账本能永久消除覆盖失败”的表述超出了证据，本文没有采纳。后续较值得单独检验的是保持 factual/NF/mixed 显式区分的紧凑账本，以及短来源锚点；两者均只是新假说，不能直接删除未提取部分或把 unclaimed 当成 NF，也不能将短锚点与输出顺序同时改变后称为单变量消融。本轮没有继续实现或调参。
