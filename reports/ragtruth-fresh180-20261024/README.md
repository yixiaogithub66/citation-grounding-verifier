# RAGTruth 新 180 条：baseline / minimal / v4.0

2026-10-24。本轮完整执行了同一批新输入上的 540 个回答 × 系统配对，没有按结果修改推理或补跑失败案例。**v4.0 正确判定 103/180，minimal 为 88/180，净增 15 条（+8.33 个百分点）；改善主要体现为原生误报减少，但 v4.0 仍有 73 个原生误报、2 个漏检及 5 份部分报告，不能称为全面稳定胜出。**

这是 RAGTruth 原生回答级幻觉检测比较，不是作者裁定后的真 FP 验收，也不测完整原子事实召回或 S/C/U 三分类准确率。所有“误报、漏检”均相对于原生标签。

## 同一批 180 条的结果

主指标为 `(TP + TN) / 180`，未知项不算正确，也不伪装成 FP/FN。已决准确率和 F1 是条件指标，其分母见表。

| 指标 | baseline | minimal | optimized-v4.0 |
| --- | ---: | ---: | ---: |
| 正确判定 / 全部 180 条 | 58/180，32.22% | 88/180，48.89% | **103/180，57.22%** |
| 已决准确率 | 58/180，32.22% | 88/177，49.72% | 103/178，57.87% |
| 已决 precision | 32.22% | 38.19% | 43.41% |
| 已决 recall | 100.00% | 100.00% | 96.55% |
| 已决 F1 | 48.74% | 55.28% | 59.89% |
| TP / FP / TN / FN | 58 / 122 / 0 / 0 | 55 / 89 / 33 / 0 | 56 / 73 / 47 / 2 |
| 未决：原生阳性 / 阴性 | 0 / 0 | 3 / 0 | 0 / 2 |
| 完整 / 部分 / 错误 | 180 / 0 / 0 | 177 / 0 / 3 | 175 / 5 / 0 |
| 完整报告率 | 100.00% | 98.33% | 97.22% |
| 回答级决策覆盖率 | 100.00% | 98.33% | 98.89% |
| 合法完整空 claims | 0 | 0 | 3 |

baseline 对全部 180 条均报出至少一个 C/U，因此其 recall=100% 不代表有区分能力。minimal 的 3 条错误全部来自原生阳性回答；其已决 FN=0、recall=100% 不能解释为全样本无漏检。v4.0 的 5 份 partial 中，3 份已有有效 C/U，可完成回答级检测；另 2 份全 S，保持未决。3 份合法完整空报告按冻结规则计阴性，并单列展示。

本批原生阳性 58、阴性 122。仅作为类别比例参照，“永远判干净”的 accuracy 会有 122/180=67.78%，但幻觉 recall/F1 为零。这不构成有用检测器，也说明当前三个系统的绝对准确率不能描述为高水平；v4.0 仍有明显过度举报问题。

## 改善幅度与不确定性

以 30 个完整来源为簇重抽，每次保留同源全部 6 个回答与三个系统，固定 seed=20261024，2,000 次 percentile bootstrap。不是把 180 个回答当作独立来源。

| v4.0 − minimal | 点估计 | 来源簇 95% 区间 |
| --- | ---: | ---: |
| 正确判定 / 全部回答 | **+8.33 个百分点** | **[+0.56, +17.22]** |
| 已决 F1 | +4.62 个百分点 | [−0.29, +9.73] |
| 完整报告率 | −1.11 个百分点 | [−4.44, +1.67] |
| 决策覆盖率 | +0.56 个百分点 | [−1.67, +2.79] |

主指标的区间支持这批新来源上的改善；F1 差值区间仍跨零。共同已决的 175 条中，v4.0 独赢 23 条、minimal 独赢 10 条；此外，minimal 未决的 3 条被 v4.0 判对，minimal 原本判对的 1 条在 v4.0 中变成未决，总正确数净增 15。共同已决子集是事后定义的描述性结果，不替代全部 180 条比较。

| 任务（每项 60 条） | 原生阳性 | baseline 正确数 | minimal 正确数 | v4.0 正确数 |
| --- | ---: | ---: | ---: | ---: |
| QA | 10 | 10 | 21 | 32 |
| Summary | 12 | 12 | 29 | 30 |
| Data2txt | 36 | 36 | 38 | 41 |

增益不均匀，QA 净增 11 条，Summary 净增 1 条，Data2txt 净增 3 条。这是描述性分层，不能据此增加任务识别分支、修改某类阈值或针对本批案例调 prompt。单轮生成和 30 个来源也不能证明跨领域、跨模型稳定胜出。

参考单价在取数前固定为 USD/百万 token：输入 0.30、缓存输入 0.006、输出 1.20；不是供应商当日正式报价或账单。reasoning 已包含在输出中，不重复收费。v4.0 的两次连接错误没有 usage，两种成本口径均保留未知总额，不能宣布总成本下降某个百分比。统一未缓存口径下，v4.0 的已知小计已高于 minimal，说明观测缓存成本与标准化成本支持不同的描述。Gemini 辅助审阅独立留档，不计入三套被测系统的推理费用。

实测 v4.0 单回答更快，但其拆分/核查关闭 thinking、复核开启；minimal 全程开启 thinking，且 v4.0 有内部并发。本轮比较的是当前既定系统，不是等预算、等并发的算法因果消融。外层四个案例并发，每个案例内三后端按固定随机顺序执行。首个请求至最后结果为 13:09:57–13:48:26（Asia/Shanghai），约 38 分 29 秒；不能将单回答时延总和当作并发总耗时。

minimal 的 3 个错误分别为两次引用契约失败、一次输出截断。v4.0 的 9 个未完成 claim 分布在 5 个回答：3 个因引文内容需要重新判定而未完成，6 个因严格 JSON 输出失败；没有整条错误。已提取目标完成率为 1384/1393=99.35%，只衡量已知目标的执行完成，不是事实提取召回率。

v4.0 仍发生 136 次拆分格式修复调用、79 个拆分降级块和 567 条降级骨架，以及 183 次单 claim 引用重问。U 复核 310 次、判决翻转 30 次，C 复核 2 次、翻转 0 次；没有 claim 语义金标，不能把翻转数直接称为净纠错收益。这些记录揭示了通用工程负担，本轮没有据此修改系统。

有效公有输出的引用机械校验分别为 50/50、2435/2435、1922/1922；只证明索引、子串和偏移合规，不证明引用在语义上支持结论。错误报告的引用没有被包装成成功。

## 数据独立性和冻结证据

- 官方上游固定为 `c103204b9ce28d6bbad859304bf30de72b8ed8fe`，`test`、`quality=good`。QA/Summary/Data2txt 各取 10 个来源组，每组保留 6 个生成模型回答。
- 按 `sha256(seed|task_type|source_id)` 排序，seed=`ragtruth-fresh180-v2-20261024`。抽样不读取标签或系统结果；先排除历史曝光与规范化输入重复，再按固定规则取数。
- 共排除 70 个已曝光来源及 1 个存在重复请求的来源；其中 68 个属于官方 test，3 个属于既往 train smoke。选中数据与已记录曝光来源、回答、相同上下文和请求无交集。选后 35 项适配/选择检查全部通过。
- 原生回答与标签未改写。QA 仅将证据段输入系统、不包含问题；Summary 保留原文；Data2txt 完整序列化 JSON，保留 null/布尔值。输入长度不合规整组先排除，本轮没有文本截断；这些限制界定了所测总体。
- 生产推理基于 `bdd636b` 的既定系统；预注册提交 `7a23bc4`、数据绑定提交 `532e083`。取数前冻结 65 个文件，执行前后与独立审计均核验一致。没有给运行时传入样本 ID、任务类别、生成模型身份或金标。
- 540 个唯一配对各只有一次外层执行；现有内部修复/复核全部保留。没有重跑失败、孤立预留、丢失结果或 I/O warning。所有有响应的调用返回相同 `deepseek-flash` 与 fingerprint。

本批现在已曝光，可用于回归和通用问题分析，不能再作为后续调优之后的未见集。原生标签分歧需要单独的作者裁定，不能将本轮 AI 结果审阅标为人工终审。v4.0 原生 FN=2，不能宣称通过此前要求的 FN=0 验收。
