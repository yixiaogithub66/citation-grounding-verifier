# 同一批 RAGTruth 30 条：baseline、minimal 与当前 v4

2026-10-23。已完成 baseline 30 条、minimal 30 条，并复用上一轮 optimized-v4.0 的原始 30 条预测。代码、Prompt、输入和原生金标均未修改；没有重抽样或失败后追加修复。**按允许利用有效 partial 的回答级口径，正确数为 14/30、17/30、19/30；但在三十条中 minimal 与 v4 都有有效判定的 28 条上，两者各正确 17 条。当前没有证据说明 v4 已稳定提高语义准确性。**

## 统一主比较

正类为原生 RAGTruth 存在幻觉标注，有效 C/U 为检测到。失败或全 S partial 记 unknown，不进 TN/FN；完整空 claims 判阴性并单列。所有主比较共同使用全部 30 条作为分母。原生 FP 不等于已经作者裁定的“真 FP”。

| --- | ---: | ---: | ---: |
| 正确决策 / 全部 30 条 | 14/30（46.67%） | 17/30（56.67%） | 19/30（63.33%） |
| 已决准确率 | 46.67%（14/30） | 60.71%（17/28） | 63.33%（19/30） |
| 已决 Precision | 46.67% | 52.17% | 56.52% |
| 已决 Recall | 100% | 100% | 92.86% |
| 已决 F1 | 63.64% | 68.57% | 70.27% |

| 未决阳性 / 阴性 | 0 / 0 | 2 / 0 | 0 / 0 |
| 回答级决策覆盖率 | 100% | 93.33% | 100% |
| 完整 / 部分 / 错误 | 30 / 0 / 0 | 28 / 0 / 2 | 26 / 4 / 0 |

Baseline 将全部 30 条都判成有问题，因此其 Recall=100%、FN=0 和 F1=63.64% 不能说明具备良好区分能力：16 条原生阴性全部误报。Minimal 的两个 unknown 都是原生阳性，其“已决 Recall=100%、FN=0”也不能说明全部 14 条阳性都被成功检出。

V4 的四条 partial 都有已完成有效 C/U，按预登记规则形成回答级判定，但仍然不是完整报告。保留原先要求完整报告的历史对照：

| 旧整条失败口径 | baseline | minimal | v4 |
| --- | ---: | ---: | ---: |
| 完整且正确 / 30 | 14/30（46.67%） | 17/30（56.67%） | 16/30（53.33%） |
| 悲观检测 F1 下界 | 63.64% | 64.86% | 58.82% |

因此不能简单宣称 v4 全面优于 minimal。完成率分母也不是事实覆盖率：baseline/minimal 返回的有效 claims 全完成，并不证明漏提为零；minimal 的两个失败没有可信提取总数，保留未知。V4 的 223/231=96.54% 只针对排除 NF 后的候选目标。

## 按任务查看

每类 10 条。原生阳性数分别为 QA 2、Summary 3、Data2txt 9。

| 任务 | baseline 正确/10 | minimal 正确/10 | v4 正确/10 | 完整/部分/错误：baseline；minimal；v4 |
| --- | ---: | ---: | ---: | --- |
| QA | 2 | 4 | 4 | 10/0/0；10/0/0；10/0/0 |
| Summary | 3 | 5 | 5 | 10/0/0；10/0/0；9/1/0 |
| Data2txt | 9 | 8 | 10 | 10/0/0；8/0/2；7/3/0 |

Minimal 在有效的 8 条 Data2txt 上 F1=100%，但另有 2 条阳性失败；不能把这个条件分数当成 10 条全对。Baseline 的 Data2txt 9/10 则完全来自全报阳性和该切片 9/10 的阳性比例。

同样本配对：v4 正确而 minimal 不正确的 4 条为 14367、2736、9526、9586；反向 2 条为 16421、27。其中 9526、9586 正是 minimal 的技术未决；其余共同已决样本净差为零。这是原生标签下的结果计数，不是逐条作者裁定。

来源级 2,000 次 bootstrap：v4 减 minimal 的正确决策/30 差为 +6.67 个百分点，95% 区间 **[-10.00, +23.33] 个百分点**；已决 F1 差 +1.70 个百分点，区间约 **[-9.73, +12.91]**，且已决 F1 的样本范围不同。小样本结果不能证明稳定优势或跨领域泛化。

以上费用使用固定历史参考单价：非缓存输入 USD 0.30/百万、缓存输入 0.006/百万、输出 1.20/百万，不是当前价格或实际账单。Baseline 的 0 是模型费用，不表示本地 CPU 资源没有成本。两条 minimal 失败的调用用量均包含在费用中。

记录缓存时 v4 费用略低；统一全未命中缓存时 v4 比 minimal 高 **28.30%**，因此不能据本轮费用说 v4 稳定更省。Minimal 的 165,316 reasoning tokens 已包含在 194,409 输出中，不再加总；v4 只有 65 次调用返回 reasoning 细分，缺少细分不等于缺少总用量。

两个 LLM 后端返回模型均为 deepseek-flash，指纹均为 `e72d3c7f663d3e1383b00b3884cb4501`。Minimal 沿用 thinking enabled/16384、一次调用不重试；v4 拆分和核查 disabled/8192、复核 enabled/16384，保留原内部并发和有限修复。这里比较现有系统，不是相等预算下的消融。

本次补跑北京时间 22:36:17–22:40:26，4 个后端执行并发，墙钟约 249 秒；原 v4 在 21:43–21:46 运行。三者没有同时随机交错执行，时延受服务负载、缓存、分阶段并发与预算差异影响；当前均值差不是受控的因果结论。

## 失败与空输出

[结构诊断](diagnostics.md) 显示 minimal 的 9526、9586 均为引文边界多出的双引号，HTTP 200、finish_reason=stop，无截断或超时证据；9526 有 1/26 条不精确引用，9586 有 11/26 条。原 minimal 没有格式修复，因此整条失败。只作离线诊断，没有静默修复、重跑或修改分数。

Minimal 唯一空输出 16452 是拒答，与 v4 共同；v4 另有 16421 空输出。同一 16421 上 minimal 返回 16 条 U，原生口径 TP，v4 为 FN。它提供了 v4 非事实排除可能漏掉事实前提的具体诊断证据，不构成通过抄写该样本修 Prompt 的授权。
