# M1、固定 claims 的 M3 与有界复核：组件对照实验

2026-10-24，Asia/Shanghai。**本轮支持继续优先处理 M1 的事实选择、独立表达和覆盖协议；M3 有局部语义收益，但被协议失败抵消大半；复核的错误标签纠正能力仍未得到检验。** 没有修改生产实现，也没有据结果调 Prompt 或重跑选优。

## 范围与对照

20 条全新、自包含的虚构回答，五个领域，中英各十条：15 条含事实，五条纯建议/偏好。45 个预先标注的覆盖目标，S/C/U 各15；每输入重复两次。参考材料经独立 AI 起草与审计，**不是作者终审金标、自然分布数据集或正式 RAGTruth v2**。事实目标可对应多条忠实原子输出，不强制模型输出相同条数。

推理前冻结提交 `a78bc92`，共65个文件；28项离线检查通过。M1与M3初判均使用同一 `deepseek-flash`、thinking disabled、8192输出上限，各一次调用，无格式/传输重试。复核沿用现有触发器、C/U顺序、逐claim上限和提示，thinking enabled/16384；仅关闭传输重试以逐次持久化。预算上限相同不表示实际计算量相同。

- M1：简短的研究提取对照 vs 原生产 M1 Prompt，输入和输出契约相同，单块、首轮提取，不含降级。
- M3：minimal 判决提示加固定claim适配器 vs 原 v4 判决提示，二者使用完全相同的45个目标与上下文；后者多输出 derivation/conflict。这是提示与结构负担的联合比较。
- 复核：直接使用持久化的当前 M3 初判；不另抽初判、不强制复核、不增加案例制造错误机会。初判不满足公共契约的行不进入本轮复核；不包含 M2 初判引文恢复。

因此，表中的简短提取/固定claim对照不等于原生产 minimal 的端到端运行。独立回答数为20，固定claim核查只有15个回答，重复没有扩大独立样本量。

## M1：内容大多保留，误纳、指代与协议仍限制可用性

两臂各40次输出、90个目标机会，全部raw可读。全部80份输出经匿名化AI语义审阅，按原答案含义匹配，不按gold字符串逐字匹配。

| 指标 | 简短提取对照 | 当前 M1 |
| --- | ---: | ---: |
| 结构有效 /40 | 31 | 31 |
| 严格完成且保真 /40 | 18 | 16 |
| 两次都严格通过的原回答 /20 | 7 | 3 |
| raw明确保留内容 /90 | 88，另2不确定 | 88，另2不确定 |
| raw独立自足目标 /90 | 76 | 76 |
| 含建议误纳或新增断言的raw输出 /40 | 16 | 13 |
| 仅结构有效输出中的误纳 /31 | 9 | 8 |
| 纯NF正确且有效 /10 | 5 | 7 |
| 事实同时被划入NF的raw输出 /40 | 0 | 3 |

严格通过要求协议有效、目标事实忠实且独立自足、粒度合理、没有误纳，事实也不能同时被整句划入NF。当前 M1 对纯NF和误纳有局部改善，但40个配对中严格结果为4次获益、6次退步、12次都通过、18次都失败，未形成整体优势。

**本批没有确认的真实漏提，不能用它证明已修好漏提。** 每臂两次不确定都来自同一个R2目标：冻结参考的端口连接细节来自建议动作，而显式事实理由只说明带电，保留双读边界，不改标注。两臂各9份结构失败中，相关21个目标仍有20个明确保留、1个上述歧义。不能把协议失败后不能交付的目标数写成语义遗漏数。

18份结构失败中13份是字符覆盖记账，另外是事实跨度、NF跨度顺序/出现次数或NF行结构。语义问题包括：建议被包装成“说话者要求/认为”的事实，条件被改成已发生状态，已有先行词未展开，或额外产生缺少条件的宽泛断言。当前M1三份事实/NF重叠输出仍同时保留事实，属于记账矛盾，不是已经观察到事实丢失。

## M3：固定输入后，判决收益与交付损失需要分开

每臂30次三目标调用，共90个判决机会。

| 指标 | 简单固定claim对照 | 当前 M3 |
| --- | ---: | ---: |
| 所有可读raw中的正确标签 /90 | 87；另3错 | 87；另3未知 |
| 公共契约有效且标签正确 /90 | 84 | 85 |
| 公共契约有效、标签正确且引证充分 /90 | 80–82 | 84–85 |
| 完整有效批次 /30 | 29 | 27 |
| 完整有效且三个标签都正确 /30 | 26 | 27 |
| 两次均完整有效且全对的原回答 /15 | 12 | 12 |

简单对照的三次已知标签错误把“材料没有记载/没有评估”当成直接反证；当前 M3 在对应位置给出 U，显示任务定义有局部作用。但当前出现一个JSON语法失败批次，以及两条 U 附带引文的协议失败。公共契约正确数最终仅净增1/90，配对为5次获益、4次退步，不足以证明稳定优势。

简单对照另有一批只因额外顶层 `type:json_object` 字段而被拒绝，其中三条claim的ID、文本和标签都正确。冻结评分器的 `label_rows/raw_label_correct` 字段先受顶层契约筛选，不能直接当成所有可读raw的统计。本表第一行采用[独立补充诊断](../research/stage-attribution-20261024/aggregation-audit.md)；该批仍保留为正式协议失败，84/90的主分数没有改变。当前三个JSON未知也没有被算成正确或错误标签。

68种不同的S/C引文组合经过两份AI审阅：五种一致判为不足，两种存在局部范围/语法回指歧义，保留上下界。不足包括漏引独立推理前提，以及用“未记载”作为反证。逐字合法引用不能证明语义充分。这里不声称推理解释的每个措辞、所有claim或完整服务已通过人工验收。

## 复核：零标签翻转，修复一条内部结构

90个计划目标中85个初判符合复核入口；其余5个保持未完成。85个可复核初判的标签全部正确，实际触发27次：C复核1次、U复核26次。

| 配对变化 | 数量 |
| --- | ---: |
| 错→对 | 0 |
| 对→错 | 0 |
| 对→未完成 | 0 |
| 标签保持正确 | 85 |
| 初判与终判都未完成 | 5 |
| v4内部结构合格且正确 | 84→85 |

唯一C复核删除了多余的 `conflict.kind_note` 字段，并补充引文，前后标签都是C。它是结构恢复；公共响应契约口径的正确数仍为85→85。26次U复核全部保持U。

**净标签纠错为0，但没有错误初判进入复核，故不能断言复核无用，也不能宣称它已证明有效。** 本批只支持它保留这些正确标签并完成一次结构恢复。没有在看完结果后追加难例或人工注入错误来扩大收益。

## 判断与记录

本轮没有候选方案被升为默认。更有依据的后续方向是保持事实/NF边界与指代完整性的同时降低M1覆盖协议失败，以及减少M3结构负担造成的交付损失。复核需要在未来独立、预登记材料中观察到自然发生的合格错误初判，才有机会估计净纠错；不能据这次零翻转直接删除或加倍复核。

Gemini High通过CLI参与设计审查、结果审查和一次审核输入更正。其错误的“按case共享复核状态”建议未采纳；首份结果审核收到的simple失败原因描述有误，已保留原文并明确纠正为顶层额外字段。没有将AI意见冒充作者裁定。

28项离线测试、29项运行耐久检查通过；独立重算154项主计数/转移一致。230个逻辑阶段与167次物理调用均有唯一记录，0未知、0补跑、0I/O警告。65个冻结文件一致，生产 `grounding/ configs/ prompts/` 相对实验前提交未变。材料短且大部分冲突明确，五个人造领域不构成工业泛化证明。
