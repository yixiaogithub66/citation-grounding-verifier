# M1 定位反馈小试验：没有新增修复收益，暂不采用

根据 Antigravity High 的通用建议，在生产代码之外实现了有界错误定位反馈：报告出错行、原文游标/出现位置或未覆盖区间，不替模型决定事实性，不修改原文或接受规则。

调用前冻结了 12 个新编英文/中文/法文/西班牙文协议案例、固定错误提取结果、24 份实际请求、源码与配置。两臂使用相同答案、原始 M1/repair Prompt、模型和拆分预算，只改变校验反馈；各执行一次 repair，首跑次数各 6，4 对并发。没有使用 benchmark 案例、词表、金标或新未见集。合成目标由 AI 草拟，未经作者终审。

| 指标 | 原有错误反馈 | 附加定位诊断 |
| --- | ---: | ---: |
| 单次修复通过原 validator | 12/12 | 12/12 |
| 合成事实目标的 source_span 均由 claims 覆盖 | 12/12 | 12/12 |
| 真实调用 / 缺失用量 | 12 / 0 | 12 / 0 |
| 输入 / 输出 token | 7,399 / 774 | 8,417 / 795 |
| 总 token | 8,173 | 9,212 |
| 固定参考费用 USD | 0.001793748 | 0.001898556 |
| 全输入按非缓存单价折算 USD | 0.0031485 | 0.0034791 |

两臂都达到本小集合的上限，详细反馈总 token 增加约 12.7%；没有观察到额外修复收益。主代理核对全部 24 个输出：两臂每例的 claim_text 列表相同，合成事实的主体、数字/符号、否定与条件保留，指令仍被排除。详细反馈在混合句案例额外将连接词登记为 NF，但该连接词仍被事实 source_span 覆盖，没有观察到事实文字被排除。

这只说明本批简单协议案例不足以证明额外反馈有价值，不证明它在复杂长答案中必然无效。词面覆盖与本批 AI 审阅也不是一般语义正确性保证。固定初始错误和一次修复的设计，不能测量初始修复触发率、端到端准确率或总体 fallback 率。

**决定：不晋升、不接入生产，不改主评测。** 保留候选、冻结材料和负面/无增益结果，后续若有独立证据再设计新实验，不能继续改这 12 例把分数调高后称泛化。

全部 24 次调用返回预定模型，运行后冻结文件未变。参考单价沿用主实验，费用是固定参考估算，不是服务商账单。原始数据见 `responses.jsonl`，汇总见 `summary.json`，逐输出核对见 `output-review.json`。本试验与 548 份端到端评测单独计数。
