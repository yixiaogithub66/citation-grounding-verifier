# NF 逐次定位修复：实际评测与决定

本轮完成 274 个输入 × 修复前/后两版，共 **548 份真实模型结果**。观察到主开发集全量正确决策小幅增加、完整报告率不变、已知 token 与费用小计下降；这些结果尚不足以证明稳定的准确率或未见泛化收益。本次修复解决了可独立复现的位置记账缺陷，保留修复，不为了分数恢复 NF 分类向所有同文位置扩散的逻辑。

## 对照如何执行

只改变原 `optimized-v4.0` 的 NF 位置解析：前版 `1106c2b`，后版 `e78fa35`。两个版本都重新调用模型，共享相同 Prompt、模型与阶段预算，未把 M1-faithful 或 combined 的差异混入对照。评测方案及脚本提交为 `b3d223a`；58 份源码/输入/计划/配置文件在调用前冻结，实际从快照执行，结束后全部哈希未变。

输入为已曝光 RAGTruth dev 180、行为草案 48、物理补充 46；没有读取或选择新未见集，没有修改金标，也不推定作者批准了补充标签。4 个案例并发，组内首跑顺序严格配平，模型只收到原文与待核查回答。模型为 `deepseek-flash`，拆分/核查 thinking disabled，复核 enabled，均沿用原配置。

实际推理时间为 2026-10-23 **20:28:21–21:00:01（Asia/Shanghai）**，约 31 分 40 秒。原始记录与冻结配置在 `results/v4-nf-live-20261023/`。

## 补充集与语义核对

行为草案标签符合 44/48→46/48；物理严格对齐且判决正确 50/58→48/58，近似对齐正确仍为 52/58。补充集全部报告均完整。物理严格差值主要来自句末标点、跨语言转述与粒度差异，不能直接读成两个新增语义错误；近似 F1 增加也主要来自输出目标数 62→61。

全部 188 条补充记录都没有观察到新旧解析器分歧，不能把这些波动归因于本修复。逐项审阅仍发现重要的通用问题：操作建议中的事实前提被整句排为 NF、拆分丢失来源归属，以及将等值断言弱化成包含关系后判为支持。它们不能靠逐字位置记账解决。详见 [补充语义审阅](supplementary-semantic-audit.md)。

主开发集的状态/完成性变化另有逐条 AI 诊断，见 [开发集语义审阅](dev-semantic-audit.md)。这类审阅核对来源和执行轨迹，不重写原生标签，不冒充作者终审。部分原生 FP→TN 伴随事实排除或证据不足却判 S，因此不能只凭整答矩阵判定优化成功。

## 确定性审计与辅助评审

- 412 项单元测试通过。548 条身份、冻结输入、Prompt 和阶段预算核对通过；4,508/4,508 条公开引用为对应原文精确子串。C/U 复核、定向重问上限、终态错误与公开判决隔离检查均为 0 违规。这些检查不证明证据蕴含或事实完整。
- 新旧纯解析器对实际 M1 返回做双重离线检查：57/548 条记录存在接受、错误反馈或 NF 账目差异，来自 47 个开发输入；补充集为 0，账目/分块核对异常为 0。这是生成后的描述性子集，不是随机对照，不能用来剥离全部模型随机性。
- Antigravity CLI **Gemini 4 Argon High** 完成了计划与结果两次只读审查，均 `SUCCESS`、正文非空、无工具调用，未操作桌面或放宽权限。两次 CLI 合计报告 34,198 token，属于辅助审查开销，不计入 verifier 的上述费用。原始请求、返回与用量在 `antigravity-design/` 和 `antigravity-results/`。
- 主代理采纳配平顺序、并列非缓存折算、保留未决分母和拆分成本诊断；不采纳“事后分叉标记可识别真实因果效应”的过强说法，也不把相同提取对象直接当作全部后续请求相同。

## 后续方向

本轮不叠加 Prompt 规则，不按案例、数据集、词表或金标触发特例。下一项限定试验是 **M1 的确定性错误定位反馈**：只向模型报告发生错误的行、原文位置与未覆盖区域，不替模型决定哪些文字是事实。先在独立合成协议案例上比较一次修复成功率、保真风险与成本；它不属于以上主评测，也不能证明端到端准确率改善。反馈只在首轮失败后生效，因此不能把“减少初始修复触发次数”作为该受控试验的指标。

主评测的所有模型设置、Prompt、评分及标签保持冻结。任何新反馈候选若没有额外证据，保持实验状态，不替换生产默认。

该限定小试验已经执行：另外 24 次真实 M1 repair 调用，原反馈与详细定位反馈均通过 12/12；详细反馈总 token 增加约 12.7%，没有观察到新增修复收益，**不接入生产**。全部合成输出另作 AI 核对，不能替代端到端评测。详见 [反馈小试验记录](../v4-m1-diagnostics-probe-20261023/README.md)。本轮没有为了追求分数叠加新 Prompt 或放宽判决。
