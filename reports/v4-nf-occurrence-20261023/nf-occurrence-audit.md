# M1 非事实跨度重复出现：冻结输出离线审计

本审计仅检查 `results/v4-m1-faithful-20261023` 已曝光的 548 条记录（dev 360、behavior 96、physics 92）。没有模型调用，没有修改推理代码、Prompt、评分器或金标，没有读取未见集。

## 可确认的结论

- 旧实现会把一条 `non_factual_spans` 行展开到块内所有相同文本出现位置；重复输出同一 NF 文本时，还会重复登记相同区间。这是确定性的记账问题，不能据此认定这些出现位置都是非事实。
- 最终接受的 payload 中，旧 v4 有 17 条、M1-faithful 有 14 条记录存在重复出现的 NF 文本。全部来自 dev；behavior 与 physics 未触发。
- 按拟定规则，每条 NF 行仅消耗一个精确出现位置，并要求 NF 起点非递减：14 个原本接受的 payload 将被拒收；20 个仍可接受、claims 完全相同，仅 NF 记账改变。
- 14 个拒收中，8 个暴露文字覆盖缺口，6 个找不到剩余的有序出现位置（含超额重复或逆序）。8 个覆盖缺口中，7 个是连接词的遗漏，1 个是列表标记。因此这批数据证明的是覆盖账目的错误，不能宣称已发现或修复 8 个事实漏检。
- 计入失败尝试的验证错误反馈，共 43/548 条记录至少一处验证结果变化。505 条在给定同一批冻结原始响应时，所有可解析 M1 调用的返回值或验证错误完全相同。未触发路径不支持“语义准确率提高”的结论。
- 变更涉及 47 个调用：20 个依然通过但 NF 账目变化；14 个通过转拒收；13 个依然拒收但错误反馈变化。错误反馈变化会改变后续 repair 提示，不能继续把冻结的 repair 响应当作新流程真实响应。
- 与实际生产解析器的严格核对已完成：854 个可解析对象的返回值或错误代码、原文全部一致。初版审计副本在 17 次调用中使用了另一种错误文案，现已改为生产原文并重跑；43 / 505 和 47 次调用的分层计数均未改变，因为这 17 次原本都已计入相对冻结旧实现的变化。文案进入模型修复提示，未作为无关差异忽略。

## 重放方法与边界

1. 从每个 `telemetry.calls` 的 `decompose` / `decompose_repair_*` 读取 `response_text`，按 `chunk_id` 和 `extraction.chunks` 恢复所属 answer 子串。
2. 从冻结 `dev/source/grounding/verifiers_v4.py` 抽取四个纯函数，逐条执行原始验证。最终接受项还必须满足非 fallback chunk、HTTP 200、finish_reason=stop。没有把失败响应当成功输出。
3. 将接受项产生的 NF 账目与最终 extraction / hard_split_recoveries 中的记录进行多重集核对：所有项均可对账，无异常。受影响的接受项中没有 hard-split recovery。
4. 在独立的离线函数副本中替换 NF 定位逻辑，生产代码未被本脚本导入或修改。规则为 `start = find(text, max(nf_prior_start, last_start_for_text + 1))`，首次同 text 的 last_start 为 -1；NF 与 claim 游标独立，不根据 covered 字符挑位置。
5. 缺少剩余位置直接 invalid；同 text 不按 reason 分组；允许不同起点的重叠出现，游标按 start+1 前进。
6. JSON 中另有“仅按 text 独立游标”的诊断，不能混同最终规则：它产生 11 个覆盖缺口，最终加入 NF 顺序后实际为 8 个覆盖错误，因全局顺序可使合法行定位到较后位置。
7. 本审计未推测新的模型重试结果、未重新计算 benchmark F1、未把结构完整性当作语义正确性。若 Prompt 同时增加位置说明，所有新模型调用仍须视为新实验。

## 建议的通用合成测试

- 同一短文本在两个不同语境出现，NF 只列一行；第二处不能自动得到 NF 覆盖，且一个完整事实 claim 可以合法覆盖第二处。
- 同 text 列两行映射两个出现位置；不同 reason 也只推进出现位置，不能重新遍历全文。
- NF 行数多于精确出现次数必须失败，不复用最后位置；不同 text 的逆序必须失败。
- 重叠精确出现（如自重叠短串）按起点推进；首个出现位于 offset 0 时不得被跳过。
- NF 与 claim 游标独立：较晚 claim 不应导致较早 NF 定位失败，也不能按 claim 已覆盖字符选择 NF 位置。
- 相同文本位于不同 chunks 时只在本块分配；合法多行重复保持全部实际位置。
- 格式修复失败后走既有骨架降级和 telemetry；任何位置错误不直接下 UNSUPPORTED 判决。
- 对无重复、顺序正确的通用多语言输入，用旧/新纯函数结果完全相同作控制。
