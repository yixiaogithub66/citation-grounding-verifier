# 本地方法诊断与反证清单

2026-10-23。本稿只读既有已曝光报告、当前 v4 源码与任务契约；没有打开新未见数据、调用模型、改变生产、改标签或运行参数。它是辅助 AI 的方法审阅，不是作者裁定。外部研究依据由本轮文献工作另行核对。

## 判断

当前最值得先验证的是 **M1 对合法 NF 排除的语义漏检审计**。最近几轮已经说明：增加结构化中间步骤可以提高执行完整率，却不自动提高判决质量；把一般保真要求写得更长也未稳定阻止事实丢失。小试应先检验一个明确机制，保留纯建议与真实拒答等反例，并将新增成本记全。不能再把组合版变成默认后用更多已知案例修它。

同批 30 条上 v4 全样本正确 19/30、minimal 17/30，但双方都有有效判定的 28 条均正确 17 条；净差主要与 minimal 的两次技术失败有关。v4 完整报告仅 26/30，minimal 为 28/30。按完整且正确口径，v4 16/30、minimal 17/30。这个证据支持把 **执行可用性与语义质量分开优化**，不支持“复杂系统已经比单次模型更准”。

## 当前可解释瓶颈

1. **语义排除是一道不可逆丢失入口。** M1 的 `non_factual_spans` 只接受精确跨度、文字覆盖和非空理由；这不能证明“没有事实”。普通 M1 排除不会进入 M3，降级骨架还可在核查/复核中再次被排为 NF。当前 small30 一个操作说明被整段 NF 排除，结果合法空报告且原生 FN；另一个真正拒答也返回空报告，必须保留两者区别。不能简单禁止空结果或让所有步骤变成 claim。
2. **拆分既可能少提，也可能把命题改弱。** 已曝光审计记录了条件丢失、来源归属丢失、等值断言弱化成包含关系。字符覆盖可能全部通过，最终标签也可能正确，但被核查的已经不是原断言。仅统计 claim 数、合法引文或最后 S/C/U 都看不到这部分问题。
3. **完成失败有独立的序列化原因。** small30 的 4 条 partial 分别涉及两类 JSON 属性名语法错误、引号边界差异、字面反斜杠序列与真正换行的差异。记录的 JSON 失败 `finish_reason=stop`，输出远低于预算；盲目提高 token 上限没有日志依据。当前客户端已请求 `response_format:{type:json_object}`，不能以“开启 JSON 模式”冒称新修复。严格 schema 能否由当前提供方支持，需要单独能力核验，不能默认支持。
4. **原生回答级标签不足以决定真 FP 优化。** QA/Summary 误报多，但没有作者最终裁定时只能叫原生 FP；Data2txt 10/10 也受该切片 9/10 阳性比例影响。baseline 全报阳性便有 9/10，说明按任务准确率不足以解释语义能力。任何减少 U 的改动都要检查是否把事实丢了、把结论改弱了或遗漏来源条件。
5. **成本主要受链路而非单提示字数决定。** v4 在 small30 的 272 次调用对比 minimal 30 次，总 token 601,172 对 225,442；缓存计费时 v4 略低，全未命中参考费却高 28.3%。加审计必须报告调用、输入/输出、缓存与非缓存两种费用，不可只展示缓存后的金额。

## 最多三个可证伪候选

### 候选 A：M1 内部的 NF 排除审计，优先

**假设：** 第一轮正确输出 JSON 后，对拟排除内容做一次角色不同的审计，能够发现建议中明确断言的能力、因果、数量、条件事实，同时不把纯建议、问题、拒答或假设前件转成事实。它针对的是“合法但语义错误的排除”，不同于 combined 对未覆盖文字的残留补提取，也不同于已失败的格式错误定位反馈。

**最小干预：** 审计只看原回答/所需边界上下文及 M1 输出，不看来源证据，不能因为来源支持某命题就往回答里补事实。优先作为独立 shadow 实验：保持生产输出不变，审计另列 `embedded_assertions`、原文跨度、保留/质疑理由。若实验继续实现恢复，应仍由 M1 产生原子目标，冻结每块至多一次审计与失败行为；M3 不拆分、不拼句、不下代码事实性判决。不以“零 claims”单独触发，避免只修一种外观；触发条件可统一为存在拟 NF 排除，但必须计入大量正常 NF 的成本。

**独立合成设计：** 在 science、systems、ordinary、business 四领域各写三组对照，共 12 组/36 输入：纯动作建议；同动作嵌入显式因果/数值事实；同事实的普通陈述。换词、主语与数值不沿用任何 benchmark 文本。另可将其中半数组变为中文，语言安排先固定。为每例预写“必须保留事实集合”和“不得凭空添加断言”，不要用词面 claim 数评分。语义标签是 AI 草案，不冒充作者终审。

**必要反例：** “试试重启”不自动断言重启一定有效；“如果 P 就执行 Q”不自动断言 P 已成立；“尝试把数值设为 x，看看是否有效”不等于断言 x 会启用功能；拒答和问句仍允许空报告。针对明确的“设为 x 会启用 Y”应保留因果与数值，但不得改成有人实际操作过。

**失败标准：** 没有增加被保留的预声明事实，或新增事实化建议/假设；恢复了目标却丢条件、主体或增加范围；以更多 unknown/失败隐藏漏检；成本增长而净语义改正不为正。小试双臂全对则为无信息结果，不晋升。保真恢复和后续 S/C/U 应分别报告；影子审计不能声称已改善端到端检测。

### 候选 B：对原回答到原子命题的限定/归属保真做独立审计

**假设：** 与继续给 M1 加长规则相比，单独要求识别“原回答实际断言是否蕴含该 claim，claim 是否丢失该断言的关键限定”更容易发现条件、量词、主体、来源的弱化和错绑。它与 A 正交：A 查排除区，B 查已提取 claim。先单独测，不直接联合。

**最小干预：** 只对原答案与已有 claim/source_span 做影子检查，输出 `faithful/strengthened/weakened/attribution_changed/unclear` 及最小见证跨度；不得用来源证据改写回答，不把“整个回答蕴含 claim”单项检查误当完整性证明。审计报告仍是模型判断，不能用关键词比较冒充证明。若提出修订，只能作为 M1 的有界新提取候选并单独记账，不静默修改送入 M3 的目标。

**独立合成设计：** 12 组原/变体，共 24 输入，覆盖条件反转、至少/恰好、可能/必然、来源归属、代词歧义、同句文字与符号同义；每组先固定必须保持的关系。加入合法同义改写、语义冗余和没有唯一指代的负对照。可先用固定错误/正确提取结果测试审计可辨识性，再小量真实端到端；固定错误实验只说明错误发现能力，不说明自然触发频率。

**必要反例：** 不要求逐字复写；不可因普通同义词变化而报错；限定只在完整上下文中共享时允许准确继承；歧义不能被自动填成常识中的唯一实体。全文事实未覆盖也不能只靠此审计发现，A/B 的分母必须独立。

**失败标准：** 正确改写被批量误拒、错误定位不能给出原答见证、改写后丢掉更多语义、同一审计只复述 M1 自述理由；净纠错不优于等预算重抽 M1。任何更强覆盖结论都要求独立的事实清单，不能只用抽取器给自己的评分。

### 候选 C：隔离序列化/定位负担的窄协议实验

**假设：** 在不更改语义判决、证据候选范围、M1 粒度及复核链的前提下，减少模型自由生成重复字符串/复杂对象的负担，可提高完成率且不增加错误引文。先明确选一个干预：当前提供方的真正 strict-schema 模式（若实测支持），或只重用 combined 的指针定位部分；不能同时加盲化复核、残留补提取和新证据角色。

**最小干预：** 当前 JSON-object 请求已经存在，新增模式必须有能力检查与实际请求记录。指针方案必须保持完整 context、稳定位置与出处身份；公共引文只能从被明确选中的原文范围生成。错误或未知指针仍失败；相关证据不能自动成为承担 S/C 的充分证据。不得通过去除引号、把 `\\n` 变成换行、折叠数字/运算符，静默救回内容不同的引文。

**独立合成设计：** 固定 claims 和上下文，覆盖引号嵌套、字面反斜杠、真实换行、负数/小数、NFKC 可安全与不可安全差异、同内容多个出处、跨段两个必要前提、U 必须空公共引文。先冻 12–16 对，统一预算、一次初判和既有重试限额；全部保留失败。位置契约、判决/证据充分性、额外 token 三者分列。

**必要反例：** `3.5` 与 `35`、`−5` 与 `5`、否定差异、单位或实体变化均不能格式修；引文真实但来自错误主体/条件仍应被语义层拒绝。证据指针只解决“引的是哪里”，不解决“该支持什么”。

**失败标准：** 表面合规提升但语义退步或引用来源错绑；以放宽 validator 获得恢复；只减少一次定向重问却增加更多 review；成功率与当前相同但 token 增加。该候选即使通过，也只能宣称执行可靠性改进，不能替代 A/B 的语义工作。

## 本轮实验设计的硬性风险检查点

- **禁止特调：** 以上领域与错误族从任务契约建立；不得把历史样本的实体、文字、ID、生成模型或金标放进提示、词表、触发器。旧案例只能在明显标记的回归层使用。
- **不得绕过复核上限：** C≤1、U≤1、固定顺序、U→C 必须同次给合格 conflict；将两个调用都挂在一个 review 标志下不等于遵守预算。新 M1 审计是新成本，必须明确登记，不能伪装为免费验证。
- **未知不等于 U：** 解析错误、引文不合法和审计失败都不能悄悄变成语义标签。纯 NF 可以空报告，误 NF 仍是语义漏检；两者需要真实内容审阅。
- **先固定实验再看结果：** 同输入双臂，顺序配平；所有失败与调用计入。新合成数据不使用模型先跑后挑难例；标签/关系在调用前冻结；尝试过即记曝光。不得用本轮 small30 当新未见确认。
- **同模型审计不是独立裁判：** 评估用预先写出的目标与反例检查所有输出；审计解释流畅、翻转多数一致都不证明正确。Gemini 可作异构辅助审查，其意见仍不是作者终审。
- **允许无增益结论：** A/B/C 各自相对共同 base，小规模用于淘汰机制；只有存在可审计净改正且没有明显边界退步，才值得扩到已曝光回归集。小试不必支持晋升，也不必马上跑整套 180×2。

优先顺序建议 A → C 或 B，具体由本轮多来源研究和 Gemini 反证决定。若预算只够一项，先选 A；它对应合法输出中最难被当前守卫发现的事实丢失入口，并可用独立语义最小对照证伪。
