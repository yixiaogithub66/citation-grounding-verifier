# Semantic audit coordination and reporting corrections

All 80 M1 outputs were read in two procedurally blinded 40-output packets. Each
target received source-grounded judgments; raw protocol failures were not dropped.
The coordinator checked both reviewers' criteria, all reported issue categories,
the red-light/ordered-process granularity boundary, and representative original
outputs for false inclusion, factual/NF overlap, conditional-to-actual promotion,
unresolved references and extra unqualified assertions. This is AI-assisted review,
not independent human gold and not two complete independent ratings of all 80.

Both reviewers used the same distinction: full-answer recoverability can preserve
content while an unexpanded explicit antecedent fails standalone. An unnamed
observatory in the answer cannot be penalized for lacking a name present only in
the evidence contexts. Faithful duplicates do not count as invented facts. Ordered
maintenance and a red indicator's contrasted meaning can be retained as coherent
single assertions; target count is not mandatory output row count.

The R2 reference includes a port connection in a preceding suggestion, while its
explicit factual reason only says energized. Both readings remain as null for
content/faithfulness in all four matching outputs (two arms × two repeats), with
the frozen reference unchanged. These outputs fail the strict joint metric on
other explicit standalone issues either way, so the headline 18/40 versus 16/40
does not depend on resolving this ambiguity. It is not counted as a demonstrated
factual omission.

All 68 distinct S/C evidence combinations were read by the coordinator and a
second AI reviewer without arm/cost mapping for that audit. Five insufficiencies
were agreed: two missed independent premises and three absence-as-contradiction
outputs. Two local-scope/omitted-governing-predicate cases differ between a strict
quoted-premise reading and indexed-passage reference resolution. Final evidence
scores retain null bounds for these two; primary and independent judgments remain
separate files. Exact substring validity is a different metric. An omitted
independent factual premise cannot be silently supplied as mere coreference.
